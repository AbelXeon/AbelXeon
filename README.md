### About

I'm a Computer Science student at Infolink University College in Hawassa, currently building **TutorLink** — a full marketplace platform connecting students with tutors across Ethiopia, built on Laravel with a custom Blade/Tailwind frontend, real-time messaging, live booking calendars, and geolocation sharing.

Most of what I know, I've learned by actually shipping things: getting a booking system's calendar logic right, wiring up AJAX polling for a chat feature, fixing the CSS bug that only shows up on a 340px phone screen. I care more about a project working correctly end to end than about collecting frameworks.

Outside of web work, I spend time in Godot experimenting with game mechanics, and in Blender learning 3D modeling — mostly just to keep building things in a different medium when I need a break from the browser.

Right now I'm focused on getting stronger across the full stack: backend architecture and database design on one side, and interfaces that actually feel considered on the other.
